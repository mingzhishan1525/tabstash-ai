Privacy Policy - TabStash AI

Effective Date: June 7, 2026

TabStash AI is a Chrome extension that helps users temporarily save browser tabs, generate AI summaries, and archive selected content to their own Notion database.

Information We Collect

TabStash AI may collect or process the following information when you use the extension:

  • User-stashed webpage data, including page URL, page title, and extracted article text or readable page content.
  • AI-generated summaries, tags, and key points.
  • Notion configuration provided by you, including Notion integration token and Notion database ID.
  • Anonymous Beta analytics events, such as extension_installed, first_stash, stash_tab, stash_all_tabs, notion_connected, notion_sync_success, and ai_analysis_completed.
  • A randomly generated user_id used only to understand Beta usage patterns.

Information We Do Not Collect

TabStash AI does not collect:

  • Passwords.
  • Payment information.
  • Full browser history.
  • Content from pages you did not actively stash.
  • Private files.
  • Precise location data.

How We Use Information

We use the collected information only to:

  • Save tabs selected by the user.
  • Generate AI summaries, tags, and key points.
  • Archive selected content to the user's own Notion database.
  • Measure Beta usage and product reliability.
  • Fix bugs and improve stability.

AI Processing

When you stash a page, the extracted page content may be sent to the TabStash AI backend and processed through DeepSeek API to generate summaries, tags, and key points.

Notion Integration

If you configure Notion, your Notion token and database ID are used only to create pages in your selected Notion database. We do not sell, share, or use your Notion credentials for any unrelated purpose.

Data Sharing

We do not sell user data.

TabStash AI uses the following third-party services only as necessary to operate the product:

  • DeepSeek API for AI processing.
  • Notion API for Notion sync.
  • PostgreSQL database for Beta analytics and product reliability metrics.

Data Retention

Your local Inbox data is stored in your browser. You can delete it by removing extension data or uninstalling the extension.

Beta analytics events may be stored on our server to understand product usage and improve reliability during the Beta period.

Security

The DeepSeek API key is stored only on the server and is never included in the Chrome extension frontend.

We take reasonable steps to protect sensitive configuration and do not intentionally expose API keys or tokens in public repositories.

Chrome Web Store Limited Use Disclosure

TabStash AI uses user data only to provide or improve user-facing features, including tab stashing, AI summarization, Notion archiving, reliability monitoring, and Beta analytics. We do not use user data for advertising, resale, or unrelated profiling.
